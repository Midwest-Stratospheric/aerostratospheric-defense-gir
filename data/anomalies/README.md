# Anomalies (open tier)

UOGW public anomaly snapshots are written here by `scripts/ingest_open_tier.py`.

- `uogw_anomalies_latest.json` — most recent pull
- `uogw_anomalies_YYYYMMDDTHHMMSSZ.json` — timestamped history

Source: https://raw.githubusercontent.com/Midwest-Stratospheric/Unified-Open-Global-Weather/main/data/latest/anomaly-report.json
