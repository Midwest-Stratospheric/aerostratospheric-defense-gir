# GIR vehicle and aircraft archive

Open-tier identifiers plus **look-like** pictures/pages and Hugging Face models.

## Fields

- `look_url` — page that shows the platform, airfield, or aircraft type
- `look_image` — direct picture when one is public
- `models` — Hugging Face models tied to that row

Aircraft types have no tail numbers.
