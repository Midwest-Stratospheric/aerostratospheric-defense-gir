# GIR vehicle and aircraft archive

Open-tier list of identifiers used with Aerostratospheric Defense GIR and xDataHub.

- Aerostratospheric platforms have `AERO-` IDs and link back to xDataHub sections.
- Public airfields use OurAirports `feature_id` values already in GIR (`OA-KBLV`, `OA-KFFO`, …).
- Military aircraft appear as **type listings only** (C-17, C-130). No operational tail numbers.

## Files

- `latest.json` — full archive
- `archive.csv` — compact table
