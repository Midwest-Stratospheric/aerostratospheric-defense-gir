# Uncertainty statement (open GIR)

| Layer | Main uncertainties |
|-------|--------------------|
| USGS quakes | Magnitude revision, location error, completeness |
| NWS alerts | Office policy differences; cancellation lag |
| EONET | Taxonomy and source heterogeneity |
| UOGW anomalies | Research screening only |
| Sentinel index | Cloud metadata; AOI sampling |
| OurAirports keywords | Name strings ≠ operational status |
| GDELT | Media bias, geocoding error |
| USAspending | Reporting lag, NAICS error |

Prefer multi-source corroboration. Check manifests for freshness. Escalate to authoritative systems for life-safety and classified decisions.
